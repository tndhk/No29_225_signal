# Overnight Dip Sniper 📈

日本株（東証プライム・日経225）を対象とした、翌日の「押し目買い」候補を抽出するPythonスクリプトです。
市場クローズ後に実行することで、テクニカル指標に基づいた推奨エントリー価格、利確価格、損切価格を算出します。

## 概要

- **目的**: 感情を排したトレード計画（IFD-OCO注文）の作成支援
- **対象**: 日経225採用銘柄を中心とした主要銘柄
- **ロジック**:
    - **長期トレンド**: 75日移動平均線より上
    - **中期トレンド**: 25日移動平均線が上向き
    - **押し目判定**: RSI(14) が 30-45 の範囲（真の押し目）
    - **トレンド強度**: ADX ≥ 25（明確なトレンド）
    - **出来高急増**: 20日平均の1.2倍以上
    - **サポート分析**: 60日安値から5%以内
    - **流動性**: 売買代金10億円以上
    - **利確・損切**: ATR（ボラティリティ）ベースの動的設定

## インストール

1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/tndhk/No29_225_signal.git
   cd No29_225_signal
   ```

2. 仮想環境を作成し、依存ライブラリをインストールします。
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

## 使い方

1. スクリプトを実行します。
   ```bash
   source venv/bin/activate
   python3 -m src.main
   ```

2. 結果を確認します。
   - コンソールに推奨銘柄リストが表示されます。
   - 実行ディレクトリに `recommendations_YYYYMMDD.csv` が保存されます。

## 設定

`src/config.py` で以下の設定を変更可能です。

### スクリーニング条件
- **MIN_TURNOVER**: 最低売買代金（デフォルト: 10億円）
- **RSI_LOWER / RSI_UPPER**: RSIの範囲（デフォルト: 30-45）
- **ADX_THRESHOLD**: トレンド強度の閾値（デフォルト: 25）
- **VOLUME_MULTIPLIER**: 出来高の倍率（デフォルト: 1.2倍）
- **PRIME_TICKERS**: 監視対象の銘柄リスト

### 価格設定
- **ENTRY_DISCOUNT_PCT**: エントリー価格の割引率（デフォルト: 2%）
- **ATR_MULTIPLIER_TP**: 利確のATR倍率（デフォルト: 2.0）
- **ATR_MULTIPLIER_SL**: 損切のATR倍率（デフォルト: 1.0）

## 主な改善点（v2.0）

### 1. エントリー価格ロジックの修正 ⚠️
**問題**: 旧バージョンでは25MAをエントリー価格に設定していたため、現在価格が25MAより上にある場合、指値注文が執行されない可能性がありました。

**解決**: 現在価格から2%割引した現実的な指値価格を設定。約定率が大幅に向上。

### 2. ATRベースの利確・損切 📊
**問題**: 固定%での利確・損切は、銘柄のボラティリティを無視していました。

**解決**: ATR（Average True Range）を使用し、銘柄ごとのボラティリティに応じた動的な利確・損切価格を設定。

### 3. RSI閾値の厳格化 📉
**問題**: RSI < 50 は「やや弱い」程度で、真の「押し目」ではありませんでした。

**解決**: RSI 30-45 の範囲に限定し、売られすぎだが過熱していない真の押し目を抽出。

### 4. ADXによるトレンド強度フィルター 📈
トレンドレス相場を排除し、明確な上昇トレンド中の銘柄のみを抽出（ADX ≥ 25）。

### 5. 出来高急増チェック 💹
機関投資家の参入を示唆する出来高の増加（20日平均の1.2倍以上）を確認。

### 6. サポート・レジスタンス分析 🎯
過去60日の安値（サポートレベル）から5%以内の価格にある銘柄を抽出し、反発の可能性が高い銘柄を特定。
